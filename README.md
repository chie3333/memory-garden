# 기억 정원사

정리하지 않아도 기억을 잃어버리지 않게 해주는 로컬 우선 개인 아카이브입니다.

생활 기록 RPG와의 전체 통합 방향은 [PROJECT_PLAN.md](./PROJECT_PLAN.md)에서 확인할 수 있습니다.

현재 버전에서는 다음을 할 수 있습니다.

- 제목이나 태그 없이 텍스트 기록하기
- 작성 시각과 출처 자동 저장
- 제목·원문·출처에서 단어 또는 문장 검색
- 기록 전체 내용 펼쳐보기
- 기록 삭제
- 손글씨 사진을 로컬 Ollama로 읽고, 결과를 확인·수정한 뒤 원본과 함께 저장
- 맥과 모바일 화면에 맞춘 반응형 화면

## 로컬에서 실행

```bash
npm install
npm run db:local:apply
npm run dev
```

터미널에 표시되는 `Local` 주소를 브라우저에서 열면 됩니다. 기록은 프로젝트 내부의 로컬 D1 데이터베이스에 저장됩니다.

## 손글씨 OCR 준비

손글씨 인식에는 로컬에서 실행되는 Ollama와 `qwen3-vl:8b` 모델을 사용합니다. Ollama를 설치하고 실행한 뒤 한 번만 모델을 내려받습니다.

```bash
ollama pull qwen3-vl:8b
```

앱의 `손글씨 사진` 탭에서 준비 상태를 확인할 수 있습니다. JPG, PNG, WebP 사진을 고르면 OCR 초안이 나타나며, 사용자가 내용을 확인하고 수정한 다음에만 기록으로 저장됩니다. 사진 원본은 로컬 R2 저장소에, 검색 가능한 확인본은 로컬 데이터베이스에 보관됩니다. Ollama가 꺼져 있거나 모델이 없어도 기존 텍스트 기록과 검색은 그대로 작동합니다.
